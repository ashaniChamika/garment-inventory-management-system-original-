# Garment Inventory Management System

A professional web-based **Garment Inventory Management System** developed using **HTML, CSS, JavaScript, PHP, and MySQL**. The system is designed to simplify and automate garment stock management, product handling, purchasing, sales, customer management, supplier management, and reporting through a centralized web application.

---

## 📌 Project Overview

The Garment Inventory Management System is a web-based application developed to help garment businesses efficiently manage their daily inventory and business operations.

The system provides a centralized platform for managing products, stock levels, suppliers, customers, purchases, sales, and reports while reducing manual work and improving data accuracy.

---

## 🎯 Project Objectives

- Manage garment products efficiently
- Track available stock and inventory movements
- Manage suppliers and customers
- Record purchases and sales
- Simplify day-to-day inventory operations
- Generate useful business and inventory reports
- Improve data accuracy and reduce manual record keeping
- Provide a user-friendly and responsive interface
- Implement secure user authentication and access control

## 🚀 Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/ashaniChamika/garment-inventory-management-system-original-.git
```

### 2. Move the Project

Copy the project folder into the XAMPP `htdocs` directory.

```text
C:\xampp\htdocs\
```

### 3. Start XAMPP

Start the following services:

```text
Apache
MySQL
```

### 4. Create the Database

Open:

```text
http://localhost/phpmyadmin
```

Create/import the project database using the SQL file provided in:

```text
database/garment_inventory_system.sql
```

### 5. Configure Database Connection

Update the database configuration according to your local MySQL settings.

```text
config/database.php
```

### 6. Run the Application

Open the project in your browser:

```text
http://localhost/garment-inventory-management-system-original-
```
